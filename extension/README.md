# SR Modkit — моды Space Rangers HD в VS Code

Расширение к [sr-modkit](https://github.com/ArtYudin89/sr-modkit): подсветка
скриптов `.rsm` и кнопки для сборки мода вместо набора команд в консоли.

Программистом быть не нужно. Всё, что расширение делает, — запускает те же
команды `srmod`, которые вы набрали бы руками, и показывает их вывод.

## Что оно умеет

**Пишет за вас правильный синтаксис.** Подсветка `.rsm` и датниковых `.txt`
(`Lang.txt`, `Main.txt`, `CacheData.txt` и всё в `CFG/`), заготовки (наберите
`dialogMsg` и нажмите Tab), а главное — подсказки по полям деклараций:

- поставили `{` внутри `planet(...)` — увидите список полей именно планеты;
- начали писать значение `government: "` — увидите шесть допустимых значений;
- навели мышь на поле — узнаете, обязательное ли оно и что в него можно класть.

Списки не выдуманы: они вынуты из самого компилятора `rsmc` (какие поля он
знает и что отвечает на негодное значение). Там, где `rsmc` значение **не
проверяет** — `item.type`, `item.useless`, `answerCommand` — подсказка честно
об этом пишет: опечатка в таком поле соберётся молча и сломается уже в игре.

**Собирает мод.** Команда **srmod: Собрать мод** (или кнопка `🔧 srmod` в
строке состояния). Есть «Собрать и поставить в игру», «Пересобирать при
изменениях», задачи VS Code для `Ctrl+Shift+B`.

**Подсказывает функции игры.** 977 имён — функции движка, функции
UtilityFunctionsPack и константы — с коротким описанием и числом аргументов.
По F12 можно перейти к определению: с `ChangeState("StX")` или `state: "StX"`
на саму декларацию, с `import from './states.rsm'` — в файл.

**Показывает замечания.** `srmod lint` запускается при сохранении, и его
находки попадают в панель «Проблемы» — с переходом на нужную строку. Ловятся
тихие ловушки `rsmc`: `DText(...)` внутри `code:` у реплики диалога, состояние
с числовым именем, опечатка в имени поля, негодное значение и — самое
незаметное — флаговое поле, записанное строкой (`race: "People"` вместо
`race: ["People"]`): такое компилятор принимает молча, а значение теряет.

**Заводит и разбирает моды.** «Создать новый мод…» делает рабочую заготовку
с комментариями. «Открыть готовый мод…» разбирает любой установленный мод
обратно в исходники.

**Проверяет `srmod.json`** — опечатка в имени поля подчёркивается сразу.

## Что нужно поставить

Само расширение ничего не собирает — ему нужен `srmod` и программы, к которым
тот обращается (`rsmc.exe`, `BlockParEditor.exe`, `rson-decompiler`, для чужих
модов ещё `RScript.exe`). Как их скачать и разложить — в
[README самого sr-modkit](https://github.com/ArtYudin89/sr-modkit#что-нужно-установить).

Коротко:

1. поставьте Python и `pip install -e <папка sr-modkit>`;
2. откройте палитру команд (`Ctrl+Shift+P`) → **srmod: Проверить инструменты**;
3. если чего-то не нашлось — впишите пути в настройки (`srmod.tools.*`) или в
   машинный `config.json`, как написано в основном README.

Если `srmod` не установлен через `pip`, укажите папку sr-modkit в настройке
`srmod.repoPath` — расширение запустит `python -m srmod` оттуда.

## Команды

| Команда | Что делает |
|---|---|
| srmod: Собрать мод | `srmod build` — `src/` → `build/` |
| srmod: Собрать и поставить в игру | то же плюс `--deploy` |
| srmod: Поставить в игру | `srmod deploy` |
| srmod: Проверить скрипты (lint) | замечания в панель «Проблемы» |
| srmod: Пересобирать при изменениях | `srmod watch` |
| srmod: Создать новый мод… | `srmod new` |
| srmod: Открыть готовый мод… | `srmod open` |
| srmod: Гейт доверия | `srmod verify --gate` |
| srmod: Тест мода в sr-lab | `sr.py test local build/` — новая игра с модом и ходы (нужен sr-lab) |
| srmod: Проверить инструменты | `srmod doctor` |

## Настройки

`srmod.command`, `srmod.pythonPath`, `srmod.repoPath` — чем и откуда запускать.
`srmod.tools.rsmc` и соседи — пути к программам (перебивают автопоиск `srmod`).
`srmod.lintOnSave` (по умолчанию включено), `srmod.buildOnSave` (выключено),
`srmod.statusBar`.
`srmod.tools.srlab` — папка sr-lab для команды «Тест мода»; `srmod.test.turns`
(15), `srmod.test.where` (где гонять: на этой системе или в Windows Sandbox),
`srmod.test.deps` (зависимости — из Steam или из агрегатора). Без sr-lab команда
недоступна, остальное расширение работает как прежде.
